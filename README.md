# Sırala Bakalım · Put Them in Order

Ülkeleri, gezegenleri, dağları ve olayları doğru sıraya diz

Seçeneklere sorunun istediği sırayla dokun. Yanlış dokunduğun bir seçeneğe yeniden dokunarak o adımı geri alabilirsin.

100.000 bölüm; her bölüm üretilir ve kurallara göre doğrulanır. Bilgi Yarışması merkez uygulamasının oyunu; ortak motor: [bilgi-motoru](https://github.com/taktemurr-ops/bilgi-motoru).
